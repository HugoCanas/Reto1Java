# Almingo: Bingo por el Medio Ambiente 🌍

## ¿Qué es Almingo?

Almingo es una aplicación multijugador diseñada para hacer que el aprendizaje sobre sostenibilidad sea divertido e interactivo. Imagina un bingo tradicional, pero con un giro educativo: cada vez que completas una línea o un bingo, en lugar de simplemente gritar "¡Bingo!", te enfrentas a una pregunta relacionada con el cuidado del medio ambiente.

Almingo no solo es un juego, sino una herramienta para fomentar la conciencia ambiental de una manera dinámica y entretenida. ¡Aprende sobre sostenibilidad mientras te diviertes con tus amigos!

## ¿Cómo funciona el bingo en Almingo?

El juego de bingo en Almingo se basa en los siguientes componentes principales:

*   **Cartones de Bingo:** Cada jugador recibe un cartón de bingo con números aleatorios.
*   **Bombo de Bingo:** El bombo contiene bolas numeradas que se extraen aleatoriamente.
*   **Preguntas Ambientales:** Cada vez que un jugador completa una línea o un bingo, debe responder correctamente una pregunta relacionada con el medio ambiente para validar su victoria.

El objetivo es completar un patrón específico en tu cartón (una línea, un bingo completo, etc.) y demostrar tu conocimiento sobre temas ambientales.

## Estructura del Proyecto

El proyecto está organizado de la siguiente manera:

*   `BomboBingo/`: Contiene el código relacionado con el bombo de bingo y la generación de números aleatorios.
*   `CartonBingo/`: Contiene el código relacionado con la creación y gestión de los cartones de bingo.

## Tecnologías Utilizadas

*   **Lenguaje de Programación:** Java
