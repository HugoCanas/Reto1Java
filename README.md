# ALMINGO

Almingo es una aplicación multijugador para jugar al bingo con tus amigos. Además de divertirte, podrás aprender sobre sostenibilidad: cada vez que consigas una línea o un bingo, se te hará una pregunta relacionada con el cuidado del medio ambiente. Una forma dinámica y entretenida de fomentar una mejor educación ambiental.
